Upload index.html, style.css, script.js, projects.js and assets/ to GitHub Pages. Keep editor.html and editor.js on your own computer alongside the website files. Open editor.html locally to manage projects. Download projects.js after editing, replace your local copy and upload the replacement to the repository root, then commit. GitHub Pages redeploys. The editor is not a password-protected server admin panel; it only edits local drafts. Reset draft loads the projects.js currently beside the editor. Existing logo URLs are preserved, not reverified.
